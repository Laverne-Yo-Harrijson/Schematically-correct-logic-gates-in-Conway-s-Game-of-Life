# Schematically correct logic gates in Conway's Game of Life
Fully functional NOT, AND and OR gates in Conway's Game of Life, shaped like standard logic symbols. Based on Nicholas Carlini logic gates.

All logic gates including the rotation mechanisms were made by Nicholas Carlini. Only applied so the inputs and the output are at the correct height for a logic circuit schematic, and drawn around it with still lives to form their corresponding symbols.
